Initial Repository Setup (executed independently for Scenario A and Scenario B):
1. Initialize local repository with default branch 'main':
   git init -b main <tmpdir>

2. Commit A on main:
   Create notes.txt with "alpha\n"
   git add notes.txt
   git commit -m "Commit A"

3. Create branch topic at Commit A, then Commit B on topic:
   git branch topic
   git switch topic
   Append "beta\n" to notes.txt
   git add notes.txt
   git commit -m "Commit B"

4. Switch to main and Commit C on main:
   git switch main
   Create todo.txt with "one\n"
   git add todo.txt
   git commit -m "Commit C"

Scenario A Commands (Rebase):
1. Demonstrate branch switching:
   git checkout topic
   git switch main
   git switch topic
2. Execute rebase:
   git rebase main
3. Verification commands:
   git rev-parse HEAD
   git rev-parse HEAD^
   git rev-parse refs/heads/main
   git rev-parse refs/heads/topic
   git symbolic-ref HEAD
   git status --porcelain

Scenario B Commands (Merge):
1. Demonstrate branch switching:
   git switch topic
   git checkout main
2. Execute merge:
   git merge topic -m "Merge branch 'topic' into main"
3. Verification commands:
   git rev-parse HEAD
   git rev-parse HEAD^1 HEAD^2
   git merge-base --is-ancestor <commit_B_sha> HEAD
   git rev-parse refs/heads/main
   git rev-parse refs/heads/topic
   git symbolic-ref HEAD
   git status --porcelain
