Initial Repository Setup:
1. Initialize local bare repository (local remote):
   git init --bare <tmpdir>/remote.git

2. Initialize local repository with default branch 'main':
   git init -b main <tmpdir>/local
   git remote add origin file://<tmpdir>/remote.git

3. Commit A on main:
   Create notes.txt with "alpha\n"
   git add notes.txt
   git commit -m "Commit A"

4. Commit B on main:
   Append "beta\n" to notes.txt
   git add notes.txt
   git commit -m "Commit B"

5. Commit C on main:
   Create todo.txt with "one\n"
   git add todo.txt
   git commit -m "Commit C"

6. Push main to remote:
   git push -u origin main

7. Create branch topic at Commit B and push:
   git branch topic <commit_B_sha>
   git push -u origin topic

Test 1 Commands (Branch and Remote Semantics on topic):
1. Switch to topic:
   git switch topic
2. Untrack notes.txt on topic:
   git rm --cached notes.txt
3. Create and stage .gitignore:
   echo "notes.txt" > .gitignore
   git add .gitignore
4. Commit changes:
   git commit -m "Untrack notes.txt and add .gitignore on topic"
5. Reference and index verification:
   git rev-parse refs/heads/topic
   git rev-parse refs/heads/main
   git rev-parse refs/remotes/origin/main
   git rev-parse refs/remotes/origin/topic
   git ls-files
   git switch main
   git ls-files

Test 2 Commands (Bulk Untracking):
1. Create dummy ignored file debug.log
2. Create .gitignore with "*.log" and "notes.txt"
3. Run bulk untrack:
   git rm -r --cached .

   git commit -m "Bulk untrack and update .gitignore on topic"
