Initial Repository Setup:
1. Initialize local repository with default branch 'main':
   git init -b main <tmpdir>

2. Commit A:
   Create notes.txt with "alpha\n"
   git add notes.txt
   git commit -m "Commit A"

3. Commit B:
   Append "beta\n" to notes.txt
   git add notes.txt
   git commit -m "Commit B"

4. Commit C:
   Create todo.txt with "one\n"
   git add todo.txt
   git commit -m "Commit C"

5. Create branch topic at Commit B:
   git branch topic <commit_B_sha>

Test 1 Commands (Recovery from accidental git reset --hard):
1. Execute accidental hard reset:
   git reset --hard HEAD~
2. Inspect reflog:
   git reflog -n 2
3. Recover commit and files:
   git reset --hard HEAD@{1}
4. State verification:
   git rev-parse HEAD
   git rev-parse HEAD^{tree}
   git status --porcelain

Test 2 Commands (Moving commit to topic and reflog branch recovery):
1. Soft reset on main:
   git reset HEAD~ --soft
2. Stash changes:
   git stash
3. Switch to topic:
   git checkout topic
4. Pop stash and commit:
   git stash pop
   git add .
   git commit -m "Commit C on topic"
5. Switch back to main:
   git checkout main
6. Recover main branch to Commit C:
   git reflog show main
   git reset --hard main@{1}
7. State verification:
   git rev-parse HEAD
   git rev-parse HEAD^{tree}
   git status --porcelain
